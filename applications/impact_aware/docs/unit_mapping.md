# CSE570 course mapping

This document maps repository modules to the supplied CSE570 Machine Learning with Python syllabus.

- **Unit I:** `unit1_preprocessing.py` demonstrates Pandas/NumPy, missing values, categorical encoding, scaling and train-test split.
- **Unit II:** `unit2_eda.py` demonstrates summary analysis, correlation, outliers, visualisation and feature selection.
- **Unit III:** `unit3_regression.py` compares Simple Linear, Multiple Linear, Polynomial, Ridge, Lasso and Elastic Net regression using MAE, MSE, RMSE and R².
- **Unit IV:** `unit4_classification.py` compares Logistic Regression, KNN, Decision Tree, Random Forest, SVM and Naive Bayes using classification metrics and confusion matrices.
- **Unit V:** `unit5_clustering_pca.py` demonstrates K-Means, Agglomerative/Hierarchical clustering, DBSCAN, PCA and silhouette score.
- **Unit VI:** `unit6_optimization.py` demonstrates pipelines, cross-validation, GridSearchCV, RandomizedSearchCV, model persistence, XGBoost (when installed) and permutation-based explainability.

Random Forest is used as a classifier because the supplied syllabus lists it in Unit IV classification. It is not represented as a Unit III regression algorithm.
