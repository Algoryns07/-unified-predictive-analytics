# Automated Testing Guide

## Running tests

Run the complete test suite from the impact-aware application directory:

```powershell
python -m pytest -v
```

## Test coverage

- Statistical drift detection
- Drift detection edge cases
- Evaluation metrics
- Experiment execution
- Multi-seed validation
- Retraining policy decisions
- Retraining cost calculations

## Limitations

Passing automated tests verifies tested software behaviour. It does not establish real-world model performance.
