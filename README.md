# Intelligent Predictive Analytics with Data Drift Monitoring

A reusable machine-learning platform for industrial and environmental predictive analytics, with emphasis on **data drift monitoring, prediction reliability and cost-sensitive adaptive model retraining**.

## Core Capabilities

- Predictive machine learning and regression.
- Statistical data drift monitoring.
- Prediction uncertainty estimation.
- Anomaly and data-quality assessment.
- Impact-aware drift investigation.
- Cost-sensitive adaptive model retraining.
- Model evaluation and explainability.
- Interactive what-if analysis.

## Independent Applications

1. **MetroPT Industrial AI** — industrial sensor analytics and predictive maintenance research.
2. **NASA Space AI** — atmospheric and environmental predictive analytics using NASA MERRA-2 data.
3. **Appliances Energy AI** — energy consumption forecasting and chronological validation.

Each application maintains its own dataset-specific processing, training and evaluation pipeline. Unrelated datasets are never combined into one training dataset.

## Project Focus

The platform investigates how changes in incoming data can affect predictive model reliability and how monitoring evidence, predictive performance and retraining costs can support better model-management decisions.
